## Deliberate deviations (documented, not bugs)
- **Query Field radius** is Border Radius/L (16) on every type and appearance, as the Figma component draws it; the Code Connect search template's `pill` attribute is not applied (confirmed with the designer 2026-10-02).
- **Button height** 48 (token / Code Connect `size="large"`) where some frames draw 52.
- **Web Awesome size attributes** keep the Code Connect long-form values (`small|medium|large`); WA 3.11 logs deprecation warnings (`s|m|l`).
- **Mobile grid gutter** 12 (token) where the Browse frame draws 16.
- **Heading/5XL letter-spacing** uses the responsive utility (−0.0342 em) rather than the frame's pixel tracking; For Business hero wraps one word differently.
- **Home hero**: copy intro plays once, the scene loops; desktop headline uses forced breaks to reproduce Figma's 3 lines; Step 1 shows the single result the frame draws; Pause control shown on tablet/mobile as drawn (SPEC said mobile has none).
- **Search combobox data** (`js/site.js` `TOOLS`): tools taken from the frames with exact logos; tier lists and verdicts are illustrative live data. Browse's header search filters the 24 cards instead of opening the combobox (as the frame implies).
- **SPEC §10 "ROAI Impact Assessment™" block** does not exist in the For Business frames and was not invented. SPEC's Verdict Card copy for Tool detail was superseded by the frame ("DATA CLEARANCE …", 6 tiers, 5 citations, "7 out of 10").
- **Skeletons** follow the Code Connect snippets (3 bones) where the Figma skeleton is richer; the loading table shows header bones as drawn.
- **`wa-select` options** (team size) are not in the design; sensible choices added.
- **Tier highlight** cross-fades per column instead of sliding one block.
