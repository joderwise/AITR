## 2. Hard rules (Dev Handoff › Implementation rules)

- **Tokens only.** Every colour, space, radius, font, duration = `var(--aitr-*)`. No hex / px literals in component CSS (1px hairline = `--aitr-border-width-s`). Raw values are allowed only for values the library itself keeps raw: glass fills (white 74% / 88%), aurora blobs, Glass/Rim gradient.
- **Modes = classes.** Dark: `.aitr-dark`. Breakpoints: media queries already inside aitr-tokens.css (desktop base, `max-width: 1279px` tablet, `max-width: 767px` mobile). Size: `size="small|medium|large"`. Pill: `pill`. Reduced motion is automatic through the tokens.
- **Don't invent states.** Only states in the States & motion tables below.
- **Code Connect mapping is binding** for the 12 core components (see §5). Use exactly those elements/classes.
- Text: only the responsive text utilities `.aitr-heading-*`, `.aitr-body-*`, `.aitr-caption-*`, `.aitr-label-*`, `.aitr-code-*`. Screen-only styles map: Display→heading-5xl, Verdict→heading-4xl, Title→heading-3xl, Section→heading-2xl, Lead→body-l, Body→body-m, Label→label-m, Meta→caption-m, Mono→code-s. New in v1.5: `.aitr-heading-hero` (60 / 52 / 40, LH 106.67%, LS −3.33%) for the Home hero headline.
- Copy text from the design verbatim. `{count}` / `{slug}` style values are live data — still render the design's literal numbers in the mockup.
